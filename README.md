Autonomous quadrotor navigation in **NVIDIA Isaac Sim**. The drone takes off,
reaches a goal or follows a waypoint mission, perceives and avoids static and
dynamic obstacles with simulated sensors, handles abnormal situations, and
lands.

> **University project, LLM-generated code.** All the code in this repository
> was generated by an LLM (Claude). Every prompt is published, in
> chronological order, in [`prompts/`](prompts/).

## Stack
- **Simulator:** NVIDIA Isaac Sim 5.1.0, running in the official container.
- **Multirotor:** Pegasus Simulator v5.1.0, providing the Iris model, rotor and drag dynamics, and IMU/GPS/barometer/magnetometer sensors. It is driven by a **custom Python backend**: all estimation, control, planning, avoidance and mission logic is written in this project.
- **Core:** pure Python 3.11 + NumPy, independent of the simulator and unit-tested in CI.

See [docs/architecture.md](docs/architecture.md) and [docs/design_decisions.md](docs/design_decisions.md).

## Quick start

Full instructions are in [docs/setup.md](docs/setup.md); they cover a local
Ubuntu PC, AWS EC2 and a native install.

```bash
git clone https://github.com/msant93/isaac-drone-nav.git
cd isaac-drone-nav
python3 scripts/check_env.py      # GPU / driver / Docker / disk diagnostics
make docker-build                 # Isaac Sim 5.1.0 + Pegasus v5.1.0 image
make smoke                        # headless takeoff -> hover -> land test
```

Host-only development (no GPU needed):
```bash
conda env create -f environment.yml && conda activate dronenav
make ci                           # ruff + mypy --strict + pytest
```

## Repository layout
```
config/      YAML parameters (drone, controller, planner, safety, ...)
scenarios/   test scenario definitions (S0–S8)
src/dronenav simulator-agnostic autonomy stack (+ Isaac/Pegasus adapter)
scripts/     standalone tools (environment check, smoke test)
tests/       pytest unit tests (no Isaac Sim needed)
docker/      Dockerfile, compose file, run scripts
docs/        architecture, design decisions, setup, report
results/     logs, plots, metrics
prompts/     every prompt given to the LLM, numbered
```
